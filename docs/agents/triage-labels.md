# 分诊标签

技能内部使用 5 个标准分诊角色。本文件把这些角色对应到本仓库实际使用的标签名。

| 技能中的角色名 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待分诊：需要维护者评估 |
| `needs-info` | `needs-info` | 待补信息：等提出人补充 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AI 代理独立完成 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色时（例如「标记为可交给代理」），使用表中对应的标签名。

如需改用其他叫法，修改右侧「本仓库标签」一列即可。
