# 21: 完整率、编辑登记、补登与状态

Status: ready-for-agent
Blocked by: 19

规格：[第一期：报表与台账](../spec.md)

**What to build:** 售后单从登记到完成都能维护，售后负责人能看到当月登记完整率并把缺的字段补上。「适用字段是否齐全」为前后端共用的纯函数（放 `contracts`；输入售后单，输出缺失的适用字段；照 R-AS-08 必填矩阵；费用项填 0 视为已填）。状态与权限照 PRD 6.5「第一阶段台账状态」与 10.1：进行中的单由登记人或负责人在「编辑登记」抽屉（S14）修改；登记人或负责人可设「已完成」（不要求齐全，记完成时间，5 秒内可撤销）；已完成的单只由售后负责人补登缺失字段（行内或抽屉，S15）；客服主管或售后负责人可取消进行中的单（二次确认、原因必填，确认取消后保留的已产生费用，AC-AS-16）；已完成、已取消为终态。已完成的单缺适用字段在列表中标黄「待回填」、售后单号旁标「缺 N 项」，进行中的单缺字段显示「—」（AC-AS-22）。P13 页头显示当月登记完整率（R-AS-08：当月按完成时间、`Asia/Shanghai`，历史导入不计；随店铺数据范围与店铺筛选变化，不随日期筛选；当月没有已完成的单显示「—」），点击筛出缺字段的已完成单。全部修改记审计；并发修改按 G7 乐观锁冲突处理。
