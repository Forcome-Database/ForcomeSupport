**关键取舍**

- **缺失判断放在应用层**：完整率、「缺 N 项」与「待回填」都用 `contracts` 的 `missingFields`，与抽屉同一条规则。坐席拿不到费用与比例，所以台账每行由后端算好 `missing`，只对已完成的单算（AC-AS-22：进行中缺字段写「—」）。当月按完成时间换成北京时间比月份（`AT TIME ZONE 'Asia/Shanghai'`）；第一期量小，按月取已完成的单在应用层数，以后变慢再挪进视图（ADR 0006 修订）。
- **状态迁移表**（ADR 0008 修订）：一行 = 当前状态 + 事件 + 守卫 → 目标状态，撤销时限是守卫列，新建登记也是一行；完成、取消时刻用事务时间 `tx.now`，与更新时间、审计时间一致，月末零点附近不会归错月。台账只有三种状态、写状态的地方两处，暂不加 lint 与触发器两道机械防线，由评审把关。
- **撤销时限**：界面倒计时 5 秒，从收到完成结果才开始数；服务端按完成时间多留 5 秒网络余量（协调者同意），超过报「已超过撤销时限，这张单保持已完成」。
- **「○」的归属与权限**（ADR 0010 修订）：接口先按能力挂 `requireCapability`，服务层再按 `aftersalesActions` 判归属，不满足 403（不记越权审计，E-24 只管店铺范围）。撤销先判归属（与状态无关），再问迁移表，所以无权的人一律 403。选项与即时折算接口给新建、编辑、补登的人都开。
- **一个接口编辑与补登**：`PATCH` 把这次提交盖到原登记上，按 `registrationItems` 逐项比较。进行中按新建规则整张校验；已完成只认原来空着的、或按 R-AS-08 算缺却已有值的项（`refillableItems`，例如退款的额外赔偿登记成 0），其余改了报「已完成的单只能补登缺失的字段」；「配件 × 数量」缺时已填的那一项不跟着解锁。改汇率与改字段同一事务、版本只加一次、各记一条审计。
- **按状态给拒绝文案**：后端（`edit.ts`）与界面（禁用项的悬停）各按状态挑一句，两处语境不同（一个是 403 报错，一个是说明为什么不能点），保留两处分支，没有硬合成一张表。
- **行内补登的冲突**：409，或快递单号上有字段错误（行内只交快递单号，补登时它唯一会报的就是「只能补登缺失的字段」），都当成「刚被别人补过」：收起编辑、刷新台账、浮层写「已刷新为最新内容」，不给重试（首次保存与重试同一处理）。
- **重试函数失败时抛出**：给 `showError` 的 `retry` 一律是「做一次、失败抛出」的函数（`completeOnce`、`undoOnce`、`cancelOnce`、`saveOnce`），否则重试再失败时同 id 的新浮层会被 notify 随即撤掉（ADR 0007 修订）。
- **Sonner 的撤掉在下一帧生效**：同一个 id 先撤掉再弹新的，新浮层会被误删（设为已完成实测出现过），失败浮层、撤销倒计时、成功浮层、冲突说明各用各的 id（ADR 0007 修订）。
- **测试工具直接写历史导入的单**：导入命令随 27，在那之前 `t.addHistoryImport` 直接引用 `aftersales` 的 schema 写表，登记为 ADR 0005 修订的例外，27 落地后取消。
- **演示时刻**：截图要对上原型的「9 月登记完整率」，本机 api 与 worker 用 `CLOCK_START=2026-09-11T10:20:00+08:00` 起（README「开发」写了用法）；空月那张另起一组 api 4514 / 前端 4515，起始时刻在 11 月。

**自己写而没用现成库的部分**

- 撤销浮层：Sonner 的 `action` 只有一个按钮，没有原型 `toast(undo=5)` 的剩余秒数与底部倒计时条，所以用 Sonner 的自定义浮层（`toast.custom`）套已有的 `ToastCard` 写，仍由 Sonner 管位置、堆叠与自动消失。
- 状态迁移表：三种状态、四行迁移，照 ADR 0008 写成纯函数表，没引 XState 一类的状态机库（与工单的迁移表同一写法）。
- 金额按分加减（`lib/cents.ts`）：只需「金额文字 ↔ 整数分」两个函数，校验与格式化复用 `contracts` 的 `isValidAmount` / `formatMoney`，没引 decimal 库。
- 演示时刻 `startingAt`：在现有 `Clock` 接口上加十来行，没引时间模拟库。
- 勾选框用 shadcn 的 Checkbox（`radix-ui`），地址栏筛选用 TanStack Router 的 `validateSearch` + zod，按北京时间归月用 PostgreSQL 的 `AT TIME ZONE`，都是现成的。

**组件库带来的细微视觉差异**（由我定，汇总给用户过目）

- 「更多」里不可用的项：Radix 的 `disabled` 菜单项收不到悬停，改为 `aria-disabled` + 拦掉选择 + Tooltip；悬停说明出在菜单左侧（原型画在右侧），因为菜单贴着视口右边。
- 「缺 N 项」与金额的悬停用原生 `title`：与原型页面 `no_cell()` 的写法一致（状态板上的深色说明是示意），同待办 20 的前例。
- 取消弹窗打开时焦点在「取消」，显示的是组件默认的焦点环（原型以描边表示默认焦点）。
- 勾选框（shadcn Checkbox）的尺寸、圆角、描边与勾照原型 `checkbox()`（16px、6px、1.5px、12px 白勾），只多了组件默认的键盘焦点环。
- 撤销浮层的倒计时条随 Sonner 的进出动效一起出现与收起。
- 快递单号在本期的列宽下能整串放下，不截断（原型列多，截成「YT262510001234…」；真实数据长时仍会截断加悬停）。
