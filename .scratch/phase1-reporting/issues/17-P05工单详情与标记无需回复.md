# 17: P05 工单详情与标记无需回复

Status: ready-for-agent
Blocked by: 16

规格：[第一期：报表与台账](../spec.md)

**What to build:** 点开一张工单能看到它的全部经过，并能把不需要回复的来信标掉。P05：标题区（主题、状态、渠道、编号、客户、订单、自动关闭预计时间）；「全程记录」卡片（客户来信、我方回复为消息卡，状态迁移与系统事件为事件行，按日期分组，分段筛选「全部 · 仅消息 · 仅事件」，卡片内滚动）；右栏 SLA 结果（每封来信的首次回复时长与达标情况）、状态流转、订单卡（平台镜像）。来信卡上「标记无需回复」：坐席与客服主管可用，按单封来信，该来信不计入 SLA，工单按迁移表变化，5 秒内可撤销，记审计。隐藏草稿、回复框、AI、审批与售后操作、合并、重新打开、内部备注、导出记录。无权店铺显示 G2，找不到显示 G3。

- [ ] 集成测试：AC-P1-01（两封都标记 → 已解决；5 秒内撤销第二封 → 回到待回复）
- [ ] 集成测试：知识库负责人、售后负责人看不到「标记无需回复」（接口拒绝）
- [ ] 集成测试：其他店铺工单详情返回无权限并写审计
- [ ] 时间线与 SLA 结果按示例夹具渲染正确
- [ ] Playwright：坐席打开工单 → 标记无需回复 → 撤销
