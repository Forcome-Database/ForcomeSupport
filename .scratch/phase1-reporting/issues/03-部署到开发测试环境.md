# 03: 部署到开发测试环境

Status: ready-for-agent
Blocked by: 02

规格：[第一期：报表与台账](../spec.md)

**What to build:** 合并到 main 后系统自动出现在内网的开发测试环境里，团队可以用浏览器访问。完整 Compose（`caddy`、`api`、`worker`、`migrate`、自建 `postgres` 镜像），caddy 托管前端静态文件并以内网子域名 + DNS-01 证书提供 HTTPS（会话 Cookie 为 `Secure`）。出站设 `HTTPS_PROXY` 与 `NO_PROXY`（ADR 0003）。内网自托管运行器以独立系统用户、只能操作开发测试 Compose 项目的标签领取部署任务；部署前先跑 `migrate`；部署完成后对该版本跑 Playwright 冒烟。开发测试环境默认全部用 Fake，并加载示例数据夹具。

- [ ] 合并到 main 触发部署到开发测试环境，PR 与 main 的构建测试仍在云端运行器
- [ ] 内网域名 HTTPS 可访问，证书受信
- [ ] 部署后 Playwright 冒烟（开发登录 → 看到顶栏）自动运行并在 Actions 上报告结果
- [ ] 开发测试环境的外部客户端默认为 Fake；默认禁止向白名单外地址发信的开关已就位
- [ ] 运维所需清单（放行域名、`NO_PROXY`、内网 DNS）写进部署说明
