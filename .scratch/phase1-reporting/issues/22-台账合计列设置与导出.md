# 22: 台账合计、列设置与导出

Status: ready-for-agent
Blocked by: 20, 21

规格：[第一期：报表与台账](../spec.md)

**What to build:** P13 成为可交付的台账。筛选（日期按费用发生日、店铺、处理方式、责任）；FSH 承担 $、工厂承担 $ 两列（工厂承担 = 产品成本 × 产品成本组工厂比例 + 运费 × 快递物流组工厂比例 +（额外赔偿 + 其他）× 其他费用组工厂比例），悬停显示三组比例，三组相同写一个值、不同写「按费用项」可展开；合计行（产品成本、运费、额外赔偿、FSH 承担、工厂承担），首列与合计行在横向滚动时固定。合计来自一个**售后成本 SQL 视图**（非待确认单的四项费用美元冻结值，已取消的单计已产生部分），此视图将被报表复用（AC-RP-01）。「列设置」显示或隐藏列，默认隐藏「配件 × 数量」。「导出 Excel」：服务端 exceljs 按当前筛选与字段权限同步生成，记审计（S11）。不显示报备、协商、结算列与「✦ 积加有单号」预填。

- [ ] 单元测试：承担金额计算（三组相同与不同两种）
- [ ] 集成测试：用示例夹具，合计费用为 $188.79
- [ ] 集成测试：已取消单的已产生费用计入合计
- [ ] 集成测试：坐席导出的文件不含财务列；导出写审计
- [ ] 集成测试：店铺范围过滤作用在视图查询上
- [ ] Playwright：筛选 → 导出 → 下载文件行数与列表一致
