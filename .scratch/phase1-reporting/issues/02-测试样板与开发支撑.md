# 02: 测试样板与开发支撑

Status: ready-for-agent
Blocked by: 01

规格：[第一期：报表与台账](../spec.md)

**What to build:** 让之后每张待办都能按同一个样板写测试、在没有任何外部账号的情况下端到端开发。建立规格中确认的**主接缝**测试工具：在测试进程内直接调用 Hono 应用、使用真实 PostgreSQL、以指定角色登录、注入 Fake 外部客户端、推进可注入时钟、同步把 worker 任务跑到空闲。建立 Fake 框架（每个外部客户端一个 Fake，可模拟成功、失败、超时、游标过期、断线恢复；按店铺配置选择真实或 Fake）。提供只在非生产环境由环境变量开启的开发登录。把原型示例数据 `design/spec/data.py` 转成 JSON 夹具，并提供加载器，供种子数据、Fake 回放与 Playwright 共用。前端提供登录后的空顶栏外壳。

- [ ] 一个示范集成用例：开发登录 → 调用一个受保护接口 → 断言审计里有登录记录；用例只经主接缝，不碰内部函数
- [ ] 测试工具支持：按角色建会话、推进时钟、「跑完所有已排队任务」、重置 Fake 状态
- [ ] Fake 框架提供注册与按店铺选择机制，含一个示范 Fake 的故障注入测试
- [ ] 夹具生成脚本可重复运行，产物进仓库；加载器能把夹具灌进空库
- [ ] 生产构建中开发登录不可用（有测试覆盖）
- [ ] Vitest 与 Playwright 可在本机运行，Playwright 能用开发登录打开首页并看到顶栏
