# 15: 未归属店铺队列与指定店铺

Status: ready-for-agent
Blocked by: 05, 14, 31

规格：[第一期：报表与台账](../spec.md)

**What to build:** 识别不出店铺的来信不丢，客服主管一步把它归位，管理员登记新店铺后自动归位。收件邮箱未登记的来信进入「未归属店铺」来信队列（尚未归并成工单），SLA 按原到达时间计，平台按发件域判断（亚马逊域按亚马逊 24 小时，其余按内部目标）；客服主管收到站内通知（待办 31）与钉钉工作通知（E-13）。P04 上只对客服主管显示「未归属店铺 N」入口与队列（I17）：列为来信（客户 + 主题）· 识别依据（收件地址与头字段名 + 「未登记」）· 到达 · SLA · 指定店铺；队列对客服主管不受店铺数据范围限制（来信尚无店铺），指定时下拉只列其授权店铺；没有 ✦ AI 推荐。主管点「指定」后前端先移出该行并显示 5 秒撤销浮层，窗口结束后才提交；提交后按 R-ST-02 重新识别站点、关联订单并归并成工单，SLA 保留原到达时间；操作记审计。待办 07 保存店铺后，队列中收件地址与新店铺进线邮箱匹配的来信自动按同一流程归位，客服主管收到站内通知。

- [ ] 集成测试：AC-TK-09（未登记邮箱来信 → 进入队列，不建工单，SLA 照常计时）
- [ ] 集成测试：AC-TK-11（指定店铺 → 关联订单并归并成工单，SLA 仍按原到达时间，不生成草稿）
- [ ] 集成测试：AC-P1-15（撤销窗口内撤销 → 来信回到队列、不产生工单；不撤销 → 窗口后归并）

- [ ] 集成测试：店铺范围受限的客服主管能看到队列，但指定为未授权店铺被拒绝；坐席请求队列接口被拒绝
