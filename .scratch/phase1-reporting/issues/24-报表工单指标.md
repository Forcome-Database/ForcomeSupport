# 24: 报表：工单指标

Status: ready-for-agent
Blocked by: 16, 18

规格：[第一期：报表与台账](../spec.md)

**What to build:** 客服主管打开 P17 就能看到不再需要人工导出的工单指标。`report` 用只读角色直查业务表（SQL 视图 + 索引）：**工单量**（期间内新建或重开的客户工单，不含生产厂、其他供应商来源，按新建或重开时间归期）、**首响中位数**（期间内到达的客户来信到首次回复的时长中位数，只含已回复）、**SLA 达标率（亚马逊）**（期间内到达的亚马逊应回复来信，达标数 ÷（已回复 + 已超期未回复））；「每日工单量」按渠道堆叠柱状图，悬停看当天明细。筛选：近 7 天（默认）/ 本月 / 自定义、店铺、站点；日界 `Asia/Shanghai`。「更新于」= 所用数据源中最旧的一次同步成功时间；报表注明「只统计经店铺邮箱发出的回复」，以及订单回补窗口不足 90 天时的说明。下钻：点指标、「查看明细」、柱或图例进入带筛选的 P04；无工单页权限的角色（管理员）隐藏「查看明细」、图表不可点。加载骨架 K3、无数据 K4。
