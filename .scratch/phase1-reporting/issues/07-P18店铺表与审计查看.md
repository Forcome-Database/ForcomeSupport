# 07: P18 店铺表与审计查看

Status: ready-for-agent
Blocked by: 04

规格：[第一期：报表与台账](../spec.md)

**What to build:** 管理员在 P18 登记店铺，这是来信识别店铺与订单匹配的前提。店铺表（店铺、站点、进线邮箱、平台标识、覆盖项、状态）与新增 / 编辑右侧抽屉（K8）：店铺名、平台、站点、默认站点、进线邮箱、平台标识、签名；店铺名唯一、平台标识必填、邮箱格式在字段下方报错，保存时定位到第一个错误（AC-ST-01）。每个店铺可选择外部客户端用真实还是 Fake。渠道卡区域先放骨架，积加、易仓卡显示「第二阶段接入」，不显示 17TRACK。「查看审计日志」：客服主管与管理员可查看全部，其他角色只见自己的操作（PRD 10.2），可按对象、操作人、时间筛选。示例数据夹具的 4 个店铺作为种子。

- [ ] 集成测试：三类校验错误各自返回字段级错误，不保存
- [ ] 集成测试：店铺保存记审计（完整前后值）
- [ ] 集成测试：坐席查审计只见自己的记录；管理员见全部
- [ ] 新增的店铺立即出现在各角色的店铺范围选项里
- [ ] Playwright：新增店铺抽屉校验与保存
