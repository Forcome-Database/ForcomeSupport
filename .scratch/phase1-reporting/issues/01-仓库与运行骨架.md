# 01: 仓库与运行骨架

Status: resolved
Blocked by: None (can start immediately)

规格：[第一期：报表与台账](../spec.md)

**What to build:** 一个能跑起来、能在 CI 上保持绿色的空系统。pnpm workspace 包含前端应用、后端应用和共享包 `contracts`、`calendar`、`config`；后端一个镜像，分 `api`、`worker`、`migrate` 三个入口；本机用开发用 Compose 起 PostgreSQL 18 即可运行。`core` 提供审计写入（操作人、角色、来源 IP、完整前后值，系统操作记「系统」）、业务编号生成（事务内生成，`T-` 当日序号、`S-` 全局序号）、配置读取、可注入时钟。pg-boss 接入，业务事务内插入任务即发件箱（ADR 0008）。模块按 ADR 0005 建空目录与入口导出，边界规则由 lint 在 CI 强制。数据约定按规格：UUIDv7 主键、`timestamptz`、金额 `numeric(12,2)` + 币种、`version` 乐观锁、一个模块一个 schema。

- [x] 前端、后端与三个共享包可构建；`api` 提供健康检查接口；`worker` 能消费 pg-boss 任务；`migrate` 只向前执行 drizzle-kit 生成的迁移
- [x] CI（GitHub Actions）跑类型检查、lint（含模块边界）、单元测试、集成测试（真实 PostgreSQL 18 服务容器），任一失败则 PR 不能合并
- [x] 故意写一个跨模块读表的 import，边界 lint 报错
- [x] 审计、编号、时钟各有测试：编号在并发事务下不重复、跨日重新计数；时钟可被测试注入
- [x] `report` 使用的只读数据库角色已在迁移中创建

## Comments

### 实现记录（2026-10-04，claude02）

**交付了什么**

- pnpm 工作区：`apps/web`（Vite 8 + React 19，根组件暂不渲染界面）、`apps/server`（api、worker、migrate 三个入口，tsdown 打包成 `dist/*.mjs`，一个镜像 `apps/server/Dockerfile`）、`packages/contracts`、`calendar`、`config`。
- `core`（只经 `index.ts` 对外）：可注入时钟（`systemClock`、`ManualClock`）；环境变量配置（zod 校验，缺项一次列全、不回显取值）；数据库与事务（`transaction(runtime, fn)`，`tx.now` 是事务内统一的「当前时间」）；`startRuntime` 按进程角色组装数据库与 pg-boss；发件箱 `tx.enqueue`；审计写入 `recordAudit`（操作人、角色、来源 IP、完整前后值、对象所属店铺，系统操作记「系统」）；业务编号 `nextBusinessNumber`（`T-` 北京时间当日序号、`S-` 全局序号）；数据约定列助手；乐观锁 `updateWithVersion` / `OptimisticLockError`（接口 409）；pino 日志。
- 12 个模块按 ADR 0005 建空目录、`index.ts` 与 schema（一个模块一个 schema），`report` 提供 `runReportQuery`（只读事务 + `report_reader` 角色）。
- 迁移：`0000_init`（12 个 schema、审计表、编号计数器）、`0001_report_reader_role`（只读角色与授权、默认权限）；migrate 同时安装 pg-boss 的表并建队列。
- CI：`.github/workflows/ci.yml`（static、unit、integration、image + 汇总「CI 通过」）；本机等价 `pnpm ci:local`（另含 `pnpm lint:workflows` 用 actionlint 校验工作流）；本机库 `docker-compose.dev.yml`（PostgreSQL 18，端口 4520）。

**关键取舍**

- Node 24：本机全局是 v22.22，nvm 的 v24.11.0 目录里实际是 v25.8，所以下载官方便携版 Node 24.21.0 放在会话临时目录，只在本会话的命令里前置 PATH，pnpm 10.34.6 经 corepack 取用（`packageManager` 字段）；没有改系统配置。CI 读 `.node-version`（24）。
- 版本：TypeScript 6.0 而不是 7（typescript-eslint 只支持到 6.0）；Vitest 4.1 而不是 5.0（5.0 才发布一个月）；pnpm 10 而不是 12（成熟、行为已知）；其余用当前稳定版（ESLint 10、Vite 8、pg-boss 12、drizzle-orm 0.45、zod 4、Hono 4、@hono/zod-openapi 1.6）。tsdown 是 0.x，钉精确版本 0.23.0。
- 发件箱用 pg-boss 自带的 `fromDrizzle` 适配器，在业务事务的连接上插任务；队列默认 standard 策略，只有有意去重时允许 send 返回 null。
- 边界工具在 ADR 0005 的两个候选里选 eslint-plugin-boundaries：和类型检查规则同在一条 `pnpm lint`，编辑器里即时提示，能用 ESLint 的 Node API 把判定固化成测试。另用 `no-restricted-syntax` 禁止模块 `index.ts` 用 `export *` 或转出 `schema.ts`。
- report 只读角色用 NOLOGIN + `SET LOCAL ROLE`：不用另管一套口令，写入由数据库权限拒绝；执行迁移的用户因此需要 CREATEROLE（写进 ADR 0006 修订，生产授权随 28 号待办）。
- 第二、三期的模块（approval、factory、ai、knowledge）也建了空目录与 schema：ADR 0005 原文列了 12 个模块，边界规则与只读角色的授权一次覆盖全部，后续不用再改迁移授权。
- `order` 是 SQL 保留字：schema 名仍与模块同名，drizzle 自动加引号，手写 SQL 要写 `"order"`（schema.ts 注释与 ADR 0006 修订）。
- 审计的角色先存字符串快照，04 号待办定角色枚举后再收紧类型；审计对象类型（P27 的十种）与币种放在 `contracts`，前后端共用。不带店铺范围的审计读取只在 `core` 内部与测试里用，不对外导出（ADR 0010），P27 查询随 30 号待办。
- 金额：本待办只给 `amount`（numeric(12,2)）与 `currency` 两个列助手。PRD 11.1 要求每个费用项另存汇率、汇率日期与来源、冻结美元值，这组列（评审建议的 `money()`）要和 R-AS-08 的台账字段一起定，推迟到 19、20 号待办再补进 `core`。
- 本机 PostgreSQL 端口用 4520：本期本机可用 4510–4520，前面的留给 03 号待办的开发测试与生产两套 Compose；本机 5432、55432 已被其他工作区占用。

**自己写而没用现成库的部分**

- `scripts/lint-workflows.mjs`（十几行）：只是用 Docker 运行现成的 actionlint 镜像，免去本机安装与 Windows 路径转换问题。
- `scripts/check-migrations.mjs`（约 40 行）：drizzle-kit 没有「表结构与迁移是否一致」的命令（`drizzle-kit check` 只查迁移之间的冲突）；常见的 generate + `git status` 判定在本机有未提交改动时误报，所以改成生成前后比对迁移目录的文件哈希，本机与 CI 一样可用。
- 测试库（`apps/server/test/global-setup.ts`、`database.ts`）：规格要求真实 PostgreSQL 18；用 PostgreSQL 自带的 `CREATE DATABASE … TEMPLATE` 每个测试文件复制一个已迁移的库，不到 100 行。Testcontainers 每次起容器太慢且 CI 已有服务容器，pg-mem 之类不是真 PostgreSQL。
- `ManualClock`（约 50 行）：规格要求业务代码接收显式的当前时间；伪造全局计时器（如 @sinonjs/fake-timers）会连带影响数据库连接与 pg-boss 的超时。pg-boss 12 自带的 TestClock 只管 pg-boss 自己的计时，不覆盖业务时间。
- 业务编号计数器：数据库 sequence 不能按天重置，事务回滚还会跳号，所以用计数行 upsert（行锁排队、回滚不占号）。
- 业务日界 `businessDate` 用内置的 `Intl.DateTimeFormat`，不引日期库。

**界面**：本待办没有界面——前端根组件渲染空，外壳随 02、04 号待办按原型实现，所以没有截图与组件库视觉差异。
