# 01: 仓库与运行骨架

Status: ready-for-agent
Blocked by: None (can start immediately)

规格：[第一期：报表与台账](../spec.md)

**What to build:** 一个能跑起来、能在 CI 上保持绿色的空系统。pnpm workspace 包含前端应用、后端应用和共享包 `contracts`、`calendar`、`config`；后端一个镜像，分 `api`、`worker`、`migrate` 三个入口；本机用开发用 Compose 起 PostgreSQL 18 即可运行。`core` 提供审计写入（操作人、角色、来源 IP、完整前后值，系统操作记「系统」）、业务编号生成（事务内生成，`T-` 当日序号、`S-` 全局序号）、配置读取、可注入时钟。pg-boss 接入，业务事务内插入任务即发件箱（ADR 0008）。模块按 ADR 0005 建空目录与入口导出，边界规则由 lint 在 CI 强制。数据约定按规格：UUIDv7 主键、`timestamptz`、金额 `numeric(12,2)` + 币种、`version` 乐观锁、一个模块一个 schema。

- [ ] 前端、后端与三个共享包可构建；`api` 提供健康检查接口；`worker` 能消费 pg-boss 任务；`migrate` 只向前执行 drizzle-kit 生成的迁移
- [ ] CI（GitHub Actions）跑类型检查、lint（含模块边界）、单元测试、集成测试（真实 PostgreSQL 18 服务容器），任一失败则 PR 不能合并
- [ ] 故意写一个跨模块读表的 import，边界 lint 报错
- [ ] 审计、编号、时钟各有测试：编号在并发事务下不重复、跨日重新计数；时钟可被测试注入
- [ ] `report` 使用的只读数据库角色已在迁移中创建
