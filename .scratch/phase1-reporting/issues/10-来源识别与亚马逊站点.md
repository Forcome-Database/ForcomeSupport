# 10: 来源识别与亚马逊站点

Status: ready-for-agent
Blocked by: 08

规格：[第一期：报表与台账](../spec.md)

**What to build:** 非客户来信不再污染工单与指标，亚马逊工单带正确站点。可配置的发件人规则表（亚马逊通知发件地址、Shopify 系统邮件、已登记生产厂邮箱、`List-Unsubscribe` 等头），判定 客户 / 平台通知 / 生产厂 / 其他供应商 / 营销；规则表与已登记生产厂邮箱随种子数据提供。平台通知与营销归档、不建工单；生产厂与其他供应商来信照常归并建工单并在工单与消息上标注来源，这类来信不是「应回复来信」。亚马逊按发件域（amazon.com / .ca / .com.mx）识别站点，工单保存站点字段；无法判定时取店铺默认站点。P04 列表显示来源标注与站点。
