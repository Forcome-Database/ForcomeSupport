# 19: 台账曳光弹：新建登记

Status: claimed
Blocked by: 04

规格：[第一期：报表与台账](../spec.md)

**What to build:** 售后负责人在 P13 登记第一张售后单并在列表里看到它。售后单表（与第二期同一张表，字段见 PRD 11.1：店铺、站点、订单号、客户、登记人、负责人、费用发生日、完成时间、创建路径含「手工登记」「历史导入」，简化状态 进行中 / 已完成 / 已取消）；`S-日期-全局序号`。「新建登记」右侧抽屉（S14）按处理方式（调整安装方式 / 寄配件 / 退款或部分补偿）只列适用字段（R-AS-08 必填矩阵）；来源工单可不填，填了则带入店铺、站点、订单号、客户；负责人必填，只能选有该店铺数据范围的售后负责人（登记人是售后负责人时默认本人，该店铺只有一位售后负责人时默认此人）；选责任类型后三组承担比例按种子数据预填，0–100 整数、两侧互补（AC-AS-11 的校验部分）；任一组工厂比例大于 0 时生产厂必填（寄配件按配件 SKU 预填）；责任为「其他」时理由必填；「退款或部分补偿」的款项记在额外赔偿且须大于 0，没有单独的退款金额字段。本张金额先以原币保存（汇率见待办 20）。P13 最简列表（售后单号、客户、店铺与站点、处理方式、责任、状态、费用列）。客服主管与售后负责人可新建；坐席只读、不见财务字段；知识库负责人与管理员无权进入。种子数据：责任类型默认比例、SKU 与生产厂对应。
