# 23: 成员停用与改派队列

Status: ready-for-agent
Blocked by: 06, 19

规格：[第一期：报表与台账](../spec.md)

**What to build:** 成员离开时，他负责的售后单不会没人管。P20 手工停用（K10 二次确认）前检查该成员负责的进行中售后单，有则拒绝并提示先改派（第一期工单没有负责人）。钉钉离职自动停用时，`org` 发「成员已停用」事件，`aftersales` 把其负责的进行中售后单标记为「待分配」进入客服主管的改派队列（归属标记，不改业务状态）；客服主管或售后负责人可在 P13 改派负责人。

- [ ] 集成测试：AC-ST-02 改写版（负责进行中售后单 → 停用被拒绝并提示先改派）
- [ ] 集成测试：AC-ST-05 改写版（离职 → 自动停用、会话失效、售后单进入改派队列）
- [ ] 集成测试：改派后售后单状态不变，负责人变更记审计
- [ ] 集成测试：跨模块只经事件联动，`org` 不直接读写售后单表
