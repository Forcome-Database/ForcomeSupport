# 05: 钉钉同步与扫码登录

Status: ready-for-agent
Blocked by: 04, 31

规格：[第一期：报表与台账](../spec.md)

**What to build:** 成员与部门自动来自钉钉，成员用钉钉扫码登录。钉钉客户端（真实 + Fake，按环境变量切换）：Stream 长连接接收通讯录事件、每小时全量对账（常驻连接用 advisory lock 选主）；成员与部门只读同步。登录页按 G11（扫码二维码、2 分钟过期刷新）；扫码登录换出与开发登录同一种会话；被拒按 G12 三种原因（未分配角色、已停用、会话过期）。钉钉离职自动停用：立即失效会话、不能再登录（改派售后单见待办 23）。同步失败时保留上次数据、登录与权限不受影响；P18 钉钉卡超过 2 小时未同步显示「同步延迟」、连续 3 次失败显示「连接异常」，只给管理员发站内提醒（待办 31），不出全站横幅（E-32、6.9）。钉钉工作通知发送能力（内容带对象编号与时间，同一人 5 分钟内合并）一并落在 `core`，供后续通知使用。钉钉内免登不在第一期。

- [ ] 集成测试（Fake）：通讯录新增、变更、离职事件分别正确反映到成员与部门
- [ ] 集成测试：离职成员的现有会话立即失效，再次登录被拒绝并显示「账号已停用」
- [ ] 集成测试：未分配角色的钉钉用户登录被拒并显示原因（G12）
- [ ] 集成测试：同步失败时成员数据不变，管理员收到站内提醒，不产生全站横幅；连续 3 次失败，连接状态接口返回钉钉连接异常（AC-P1-22；P18 钉钉卡的展示在待办 09）
- [ ] 集成测试：同一人 5 分钟内的两条工作通知合并为一条
- [ ] 已分配角色与店铺的成员扫码登录后进入默认首页，只见授权店铺（AC-ST-06，Fake 钉钉）
- [ ] 真实客户端经 `NO_PROXY` 直连，开发测试环境有切换开关
