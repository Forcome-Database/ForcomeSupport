# 05: 钉钉同步与扫码登录

Status: ready-for-agent
Blocked by: 04

规格：[第一期：报表与台账](../spec.md)

**What to build:** 成员与部门自动来自钉钉，成员用钉钉扫码登录。钉钉客户端（真实 + Fake）：Stream 长连接接收通讯录事件、每小时全量对账（常驻连接用 advisory lock 选主）；成员与部门只读同步。扫码登录换出与开发登录同一种会话；未在本系统分配角色的钉钉用户不能进入。钉钉离职自动停用：立即失效会话、不能再登录（改派售后单见待办 23）。同步失败时保留上次数据、登录与权限不受影响、管理员收到站内提醒（E-32）。钉钉工作通知发送能力（内容带对象编号与时间，同一人 5 分钟内合并）一并落在 `core`，供后续通知使用。P18 的钉钉连接卡显示最近同步时间。

- [ ] 集成测试（Fake）：通讯录新增、变更、离职事件分别正确反映到成员与部门
- [ ] 集成测试：离职成员的现有会话立即失效，再次登录被拒绝
- [ ] 集成测试：同步失败时成员数据不变，管理员收到站内提醒
- [ ] 集成测试：同一人 5 分钟内的两条工作通知合并为一条
- [ ] 已分配角色与店铺的成员扫码登录后进入默认首页，只见授权店铺（AC-ST-06，Fake 钉钉）
- [ ] 真实客户端经 `NO_PROXY` 直连，开发测试环境有切换开关
