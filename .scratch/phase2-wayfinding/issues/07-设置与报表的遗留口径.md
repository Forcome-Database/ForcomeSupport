# 07: 设置与报表的遗留口径

Type: grilling
Status: open
Blocked by: None
Map: [第二期探路地图](../map.md)

## Question

四方对照（`../assets/四方对照-设置报表与全局.md`）留下的业务口径，按完整版逐条定：

1. P18 渠道卡上的「订单回补」行第二期还要不要（D13）？（建议：保留。）
2. 店铺签名、SLA 覆盖、模板适用店铺三个入口（D11）？（建议：各归一处——签名在 P18 店铺抽屉（管理员），SLA 覆盖在 SLA 页、模板适用店铺在模板页（客服主管），P18 店铺表只读汇总。）
3. 停用成员或钉钉离职时，他发起的审批单、人工操作清单、锁定给他的待确认售后单交给谁（D18、D20）？（建议：手工停用交给弹窗里选的工单接手人；钉钉离职交给该店铺的客服主管，写进改派通知。）
4. 停用时选的工单接手人限店铺数据范围（D19）？（建议：限。）
5. 报表「工厂承担」卡的「本月」口径与下钻（D41）？（建议：按比例确认时间归月，与结算一致；下钻 P14；要财务权限；随店铺、站点筛选，不随标签。）
6. SKU 成本表在哪维护（D32）？（建议：P24 的 SKU 表加「成本」列，修改记审计。）
7. 改 IMAP 服务器时 SMTP 跟不跟着变？（建议：没手动改过的跟着推出，手动改过的不动。）
8. 「查看错误日志」「查看失败记录」的去向（D6）？（建议：P26 系统状态的外部调用记录，按渠道筛选。）
9. 工作时间在 SLA 页可编辑还是只读（D49）？（建议：客服主管可编辑，记审计。）
10. P20 成员的「语言」怎么改、记不记审计（D21）？P20 是否在任何阶段都不分配生产厂对接人（D22）？（建议：语言在成员抽屉里改并记审计；生产厂对接人只在 P24 维护。）

报告里其余漂移是原型与 PRD 的文字修正，归「设置与报表的原型与 PRD 补齐」。P25 灰显行（D33）因全部用途启用而作废。
