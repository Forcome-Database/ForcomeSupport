# 讨论：部署拓扑与数据合规

## Question

生产系统私有化部署在公司服务器、经代理访问外部，拓扑与合规怎么定？

要定：服务器所在地域（中国大陆 / 香港 / 海外）；出境代理的形态与责任方；买家个人信息的存储位置、加密与脱敏、留存期限（亚马逊数据保护政策、CCPA、墨西哥 LFPDPPP、中国个人信息出境规则）；审计日志保留 ≥ 2 年的存储方案；外部回调（Gmail 推送、钉钉事件）如何进入内网；出站代理的固定出口 IP（积加 IP 白名单默认拒绝）；工厂人员手机在钉钉内打开工厂工作台的外网访问方式（公网入口 / VPN / 零信任网关）；Docker Compose 下的服务划分与备份。
Claude 经 NewAPI 网关接入（已定，不讨论其合规与网络）。参考：「调研：亚马逊 SP-API 退款、取消、读订单与开发者资质」「调研：私有化部署经代理调用 Claude API」的结论（可并行，结论出来后复核）。

## Answer

2026-09-24 与用户逐轮讨论定出。拓扑见 ADR [0003 内网零入站与工厂工作台单一公网入口](../../../docs/adr/0003-内网零入站与工厂工作台单一公网入口.md)，数据见 ADR [0004 不设个人信息脱敏与留存限制](../../../docs/adr/0004-不设个人信息脱敏与留存限制.md)。

- **地域**：服务器在中国大陆，放在公司，Docker Compose 部署。
- **出站**：积加、钉钉、易仓从公司固定 IP 直连（积加白名单登记该 IP）；境外服务经公司已有的固定境外代理出去。系统只配一个代理地址，运维按域名分流，我们交放行域名清单。
- **入站**：外部系统零入站，全部由系统主动拉取或走长连接。唯一的公网入口是公司固定 IP 上的一个子域名，HTTPS（Let's Encrypt，DNS 验证），只放行工厂工作台和钉钉免登路径，并限制访问频率。
- **合规**：不考虑。个人信息不脱敏、不删除；审计记录完整的前后值，保留 ≥ 2 年；发给模型的来信用原文。
- **备份**：每天凌晨做一次全量，复制到公司另一台机器或 NAS；保留 30 份日备份和 12 份月备份；RTO 4 小时，每季度做一次恢复演练。
- **环境**：一套生产、一套开发测试（接各平台沙箱与开发店铺）。
- **留给后续**：Docker Compose 服务怎么拆，归「讨论：后端与数据库选型」；CI/CD、监控告警、密钥管理，归「讨论：工程与运维」。
