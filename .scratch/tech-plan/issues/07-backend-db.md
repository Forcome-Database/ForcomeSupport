# 讨论：后端与数据库选型

## Question

后端用什么 TypeScript 框架与数据访问方式，数据库用什么？

要定：Node 运行时与框架（如 NestJS、Fastify、Hono）；ORM 或查询构建器（如 Drizzle、Prisma、Kysely）；数据库（推荐 PostgreSQL）及版本；迁移管理；共享校验（zod）与接口约定（REST/OpenAPI、tRPC）；审计日志与乐观锁、编辑锁（R-TK-06）、审批处理锁（R-AP-03）的实现基础。
