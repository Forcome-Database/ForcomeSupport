# 调研：私有化部署经代理调用 Claude API

## Question

生产系统部署在公司服务器、经代理访问外部，如何稳定合规地调用 Claude？

需要查清：
- 可选接入渠道：Anthropic API 直连、AWS Bedrock、Google Vertex AI；各自在经代理访问时的可行性与区域。
- 数据使用与保留政策（是否用于训练、保留时长、零数据保留选项），对买家个人信息的影响。
- 当前可用模型及定位（按草稿生成、分类与风险拦截、译文与摘要等用途推荐分工），价格与提示缓存。
- 工具调用与 MCP 支持现状（与 PRD「MCP 形式适配器」的关系）。
- 中国大陆网络环境下调用的已知限制（以官方可用区域与条款为准）。

## Answer

详见分支 `research/claude-api`（提交 21300fa）的 `docs/research/Claude接入.md`，含 8 条待确认与来源。

- **合规是阻塞项**：中国大陆、香港、澳门不在 Anthropic 支持地区清单；商业条款 D.2 要求遵守该清单，出站代理只改变出口 IP，不改变使用地与使用主体。Bedrock 中国区无 Claude，Vertex 无大陆端点。
- **可行路径**：由支持地区主体（如美国或墨西哥子公司）签约，把一个小的「模型网关」部署在美国区，私有化业务系统经专线或 VPN 调用它。签约主体与股权是否满足条款须法务确认。
- **渠道**：首选 Anthropic API 直连（或 Anthropic 运营的 Claude Platform on AWS），功能最全、可申请零数据保留；Bedrock、Vertex 不支持批处理与 MCP 连接器。
- **数据**：API 数据默认不用于训练、30 天删除；零数据保留需按组织开通（批处理、Files API、MCP 连接器不在范围内）。建议发给模型前把买家姓名、邮箱、电话、详细地址替换为占位符。
- **MCP**：不用 Anthropic 托管的 MCP 连接器（要求适配器公网可达，且含退款、取消等写动作）。适配器只在内网，后端作 MCP 客户端；只把查订单、查物流、查库存暴露为模型工具，写动作由模型提出后走发送判定与审批。
- **超时**：SDK 默认超时 10 分钟、重试 2 次且超时会重试；须在业务层设 60 秒总时限（PRD E-03），据此配置单次超时与重试。
- **模型与成本**（每天约 300 封）：3 版草稿用 Claude Sonnet 5；风险拦截、意图分类、回复检查、译文与摘要用 Claude Haiku 4.5。混合约 500 美元/月，全 Sonnet 约 590 美元/月，草稿换 Opus 5.5 约 800–1,200 美元/月；留 1.3 倍余量预算约 650–800 美元/月，须用真实来信校准。API 最低档月上限 500 美元，上线前升档或申请提额。

**对其他待办的影响**：「讨论：部署拓扑与数据合规」必须把「模型网关放在支持地区」和签约主体作为前提讨论；「讨论：集成层设计与「MCP 形式」的含义」采纳上述 MCP 建议作为起点。

## Comments

2026-09-24：用户决定 Claude 经 NewAPI 网关接入，不考虑调用合规与网络问题；本调研中「合规是阻塞项」「签约主体」「模型网关部署在支持地区」三条不再适用。模型分工、成本估算、数据脱敏、60 秒总时限、MCP 用法建议仍然有效；需另行确认 NewAPI 对提示缓存、工具调用、结构化输出的透传。

2026-09-24：用户要求模型层同时适配 OpenAI GPT 与 OpenAI 兼容接口。本调研的模型分工与成本仅作为 Claude 方案的参考，多模型的能力差异见「调研：多模型接入能力差异（Claude、OpenAI GPT、OpenAI 兼容接口、NewAPI 网关）」，接入层设计见「讨论：模型接入层设计」。

2026-10-03（文档漂移审查）：上一条说「仍然有效」的建议里，数据脱敏已由 ADR 0004 作废（发给模型的来信用原文），「只把查订单、查物流、查库存暴露为模型工具」已由 ADR 0014 作废（`draft` 不开放工具，数据由代码预取）；模型分工按用途配置（ADR 0012）。仍有效的只有 60 秒总时限与超时配置。
